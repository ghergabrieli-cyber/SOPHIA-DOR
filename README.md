## Verify
```bash
npm test
npm run build
```

The current prototype intentionally has no framework dependency, so it can deploy as a static Vercel project immediately. Product state boundaries are already separated so accounts, database, CMS/editor workflow, audio, real quests, payments and rewards can replace local persistence incrementally without discarding the visual/product layer.

The user's approved Sophia d'Or mockup remains the primary visual reference and design source of truth.
